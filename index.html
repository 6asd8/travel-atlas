① 数据与规模

本站是中国旅行攻略原型：产品入口、搜索默认、行程助手和榜单都只做中国；海外数据仅保留作旧版深链兼容，不再作为产品主路径。 当前规模 中国 115 城 / 1765 景点，坐标为近似值、介绍为通用简介。扩容约定：每次迭代都会增加一些中国城市和景点。

v13 中国版：新增景点级「开放时间 / 闭馆日 / 预约 / 建议停留 / 官方渠道」结构化字段（首批覆盖高频 5A / 博物馆 / 山岳景区，其余如实标“未收录”）；行程加入出发日期、逐日星期与闭馆日检查；换城日按里程自动减负；新增住宿落点与预算拆分；生成后自动跳到结果区。

本轮的行程助手：填「目的地 + 天数 + 节奏 + 偏好」就能生成逐日行程（上午 / 下午 / 晚上、点与点怎么走、 今天吃什么、预算区间），全部用本站数据按规则算 —— 不联网、不要 API Key、不把出行计划发给任何第三方； 想更细（具体餐厅、实时票价、天气）可以一键把口令交给站外 AI / 平台去补，只跳转、不抓取。

中国城市的「必吃榜 / 必去榜 / 热门路线」在景点抽屉的「榜单」页签与城市列表里：只放事实性名称 + 本站自写的说明 + 来源链接，界面写明检索日期，也写明不是官方排名，不转载平台正文、不放平台截图。

② 图集与影像（全部真实影像，没有 AI 生成图）

图集以照片为主角：直接贴出真实照片（大图 + 带署名的照片墙），不再是一排跳转链接；卫星俯瞰由浏览器端联网拼瓦片（不落地保存）。 内置「精选示例」是实测可直链的 Pexels 免费图库照片（景点级 + 同城级），还可以接 Unsplash / Pexels 官方 API（用你自己申请的免费 Key，只存本机） 或只收自由许可的 Wikimedia Commons，另外支持粘贴图片直链 / 从本机选图（压缩后只存本机）；取不到图时给的是「怎么把照片弄出来」的三步， 而获奖作品 / 官方画廊入口折叠收起（版权归作者，不转载、不热链）。

内置图片扩容走的是「卫星实景」这条路：每个景点都能拿到真实影像 —— 三档缩放（街道级 z17 / 街区级 z16 / 城区级 z14）、 同城实景图墙（该城每个景点各拼一张，点开就切过去）、一键存成本机 PNG（浏览器若因跨域不放行，会如实告诉你改用右键另存）； 「我的照片」也升级成批量粘直链 / 拖拽图片文件 / 导出导入索引 JSON，并新增🩺 图片体检（逐条真加载一次，报告哪些链接已失效或被防盗链）。

为什么不是再塞一堆图库照片：本机网络实测（node tools/probe-images.mjs 的台账） Unsplash / Pexels / Pixabay 的搜索页 401 / 403、upload.wikimedia.org 与 Commons 直接不可达， 构建期拿不到「按关键词检索的免费图」，而卫星影像瓦片可直取、不需要图库许可，于是它成了内置真图的主力。

③ 攻略帖：只导流、不抓取

除了跳转小红书 / 抖音 / B站 / 大众点评 / 去哪儿 / 马蜂窝 / 知乎 / 百度等平台的站外搜索， 还提供「站内查看」：把平台页面原样内嵌（iframe）在页面里直接看，可嵌入性逐平台实测标注（B站实测无 X-Frame-Options）， 跨域限制下本站读不到、也不抓取或转存其中内容，且沙箱未开放顶层跳转；「攻略文本」仍可一键复制或存成 .txt。

④ 地图、标签与「我的清单」

地图方面：从景点 / 城市标签文字上拖拽也能拖动地图（文字已不可选中，拖拽按 4px 阈值区分点与拖）， 地名标签更醒目（更大字号 + 白底描边 + 景点左侧类别色条，光点正对坐标）；标签重叠时不再直接藏名字，而是依次试 8 个方位放置， 也可以按顶栏「🏷 标签：全部」一键显示所有城市 / 景点名字（改完记住本机）， 顶栏「道路透明度」实时调节路况着色浓淡（默认 45%，改完记住本机），点景点时地图会自动跟到该景点并让开右侧抽屉。

「我的清单」只保存在本机浏览器（localStorage），不上传服务器。

⑤ 搜「任意地址 / 地名」也能定位（v9）

搜索框不再只管收录的国家 / 城市 / 景点：输入地址、地标、区县（甚至直接输 31.2304, 121.4737）也能定位， 镜头会直接切到定位点上方并落一个金色定位针。解析顺序是「经纬度 → 本站收录（近似到城市）→ OpenStreetMap 地名服务」， 只有前两步都兜不住时才联网，且只在你按 Enter / 点「📍 定位」时请求一次（只发这一个查询词，不带任何位置 / 账号信息）， 结果缓存 60 天；解析不到就如实说「没解析出来」，不假装定位成功。定位层地址形如 #/at/31.2304/121.4737/12.5/上海外滩，可以直接分享 / 收藏。

⑥ 底图与界线合规

底图按区域自动切换：中国境内用高德瓦片（GCJ-02，含实时路况、约每分钟刷新），境外用 OSM 街道 / Esri 影像（WGS-84；高德瓦片不覆盖境外，实测会返回空图）； 地球层陆地轮廓为 Natural Earth 1:110m（公有领域）；国界与南海断续线为演示用示意界线，正式上线必须替换为自然资源部「标准地图服务」审核过的界线数据，并按《公开地图内容表示规范》报审。
