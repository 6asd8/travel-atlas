# 环游集 · 世界城市攻略地图（v13 单文件原型 · 中国 115 城 / 每城 ≥15 景点 / 日期闭馆 / 换城减负 / 预算住宿）

**地球 → 国家 / 地区 → 城市 → 景点** 四级下钻 + **我的清单**，每个景点聚合「介绍 + **真实照片 / 卫星俯瞰** + **可在页内查看的攻略帖** + 一份可直接复制 / 下载的攻略文本」。

依旧**只依赖一个文件**：`index.html`（零构建、零 npm 依赖、零外部 JS/CSS 库）。

> **v13 中国旅行工作台（本轮）**：
> **① 景点级实用信息**：`CN_PRACTICAL` 首批给高频 5A / 博物馆 / 山岳 / 海岛点位补上「票价 / 开放时间 / 闭馆日 / 是否预约 / 建议停留 / 官方渠道」；没收录的点位如实写「未收录」，不把未知说成免费。闭馆日以 `closedDays`（0=周日 … 6=周六）参与行程检查。
> **② 日期与闭馆检查**：行程条件新增出发日期，逐日显示「月/日 + 星期」；命中周一闭馆等固定闭馆日时只在顶部横幅与当日卡片提醒，**不自动改写行程**（用户可能就是想前后挪一天）。
> **③ 换城日减负**：换城当天按距离压缩点位 —— **≥300 km 当天不排白天 / 夜间景点，120–299 km 只留 1 个**；被挤出的点位列在结果里，并说明「多留一天可以排回来」。
> **④ 预算与住宿**：新增「门票 / 餐饮 / 市内交通 / 城际交通 / 住宿 / 合计」六张预算卡（**2 人同行、1 间房均摊、不含往返大交通**）。门票只累加站内已收录价格，未收录单独计数；城市住宿按「片区 + 理由 + 双人间夜区间」给落点，换城日照实分配晚数。
> **⑤ 可访问性与结果定位**：抽屉 / 行程面板补 Tab 焦点循环、关闭后回焦；点「生成行程」后自动滚到结果标题。
> 本轮**不扩城市 / 景点**，是 v8 / v9 同类的体验升级例外；下一轮继续按「每城 ≥15 个点位」扩容。

## 底图策略：按区域自动切换

| 区域 | 底图 | 坐标系 | 说明 |
| --- | --- | --- | --- |
| 中国境内（含港澳台） | 高德瓦片：`style=7` 矢量带标注 / `style=8` 纯路网 / `style=6` 卫星 | GCJ-02 | 国内速度最好；🚦 **实时路况**（`tm.amap.com`，约每分钟刷新）只有国内有数据 |
| 境外 | OSM HOT（`a.tile.openstreetmap.fr/hot`）或 OSM 标准（`tile.openstreetmap.de`） | WGS-84 | 标注多为本地语言；卫星影像用 **Esri World Imagery** |

**怎么判定「境内 / 境外」**（踩过的坑）：

1. `MapView.setRegion(lat, lng, countryId)` —— 从国家层 / 城市层进来时**直接带所属国家 id**，只要 `countryId === 'cn'` 就用高德，**最准**；
2. 用户自由拖动（没有 countryId）时，用**地球层已内联的中国版图多边形做射线法**判断（`inChinaLand`），并给 **0.6° 沿海容差**；
3. 地理数据缺失时退化成矩形框（`纬度 17–54 / 经度 73–136`）。

> **为什么不能用矩形框**：日本（京都 135.8E）、韩国（首尔 127E）、东南亚在经纬度上「看着像中国」，矩形框会把它们判成境内 → 切到高德瓦片 → **境外是空图**（实测：境外高德 `style=7` 只返回 179 字节空图，`style=6` 只返回纯海面）。
>
> **为什么多边形还要加容差**：`GEO_CN` 的海岸线是抽稀过的，**厦门、青岛栈桥**这类贴海点会落到多边外；容差就是为这种情形准备的。

实测记录：`tools/probe-world.txt`（高德境外全空、OSM 海外可用）与 `tools/probe-world2.txt`（OSM 三个镜像 + Esri 影像的海外可用性），用 `node tools/probe-world.mjs` / `node tools/probe-world2.mjs` 可复跑。

**路况会自动关**：`trafficAllowed()` 判定「底图是不是高德 + 视野是否在国内」，不满足时自动关闭并禁用 🚦 按钮，并在署名栏说明原因，而不是给一片空白。

## 演示版 → 正式版的对照

| 能力 | 现在的做法（原型） | 正式版方向 |
| --- | --- | --- |
| 底图 | 高德公开瓦片（国内）/ OSM 公共镜像 + Esri 影像（境外），无 Key | 高德官方 Key + JS API / `TileLayer.Traffic`；境外自建或商业瓦片，按其条款署名与计费 |
| 照片 | 官方图库 API（用户自带免费 Key）/ Commons / 用户自传 / 卫星实景 | 服务端统一代理与鉴权，`media` 表落 `source / author / license / fetched_at` 台账，做缩略图与 CDN |
| 攻略帖 | 站外搜索跳转 + 站内 iframe 原样内嵌（不抓内容） | 平台官方开放能力（如 B站开放平台）/ 作者授权投稿 |
| 数据 | 内联 JSON（22 国 / 159 城 / 1795 景点） | Supabase / Postgres + PostGIS，POI 表带 `source / source_license / fetched_at` |
| 收藏与图源配置 | `localStorage`（本机） | 登录后同步到服务端（需要账号体系与隐私告知） |

前端是原生 ES5+ 语法（无框架），所有拼接进 HTML 的字符串都过 `esc()`；拆成 React/Vue 时逻辑可 1:1 迁移。

## 合规与素材来源（重要）

1. **照片**：只从**官方 API / 明确许可的免费图库 / 用户自己上传**三路取图，并逐张显示作者、许可与原页链接。
   - Pexels：Pexels License（可免费使用，署名非强制但「值得给」）；Unsplash：Unsplash License；Commons：只收 CC0 / CC BY / CC BY-SA / 公有领域，按许可要求署名。
   - **获奖摄影作品**（索尼世界摄影奖、国家地理、WPA 等）版权归作者，全部**只给官方画廊外链**，页面不转载、不热链。
   - **没有任何 AI 生成图**；也没有来路不明的「网络图」。
   - 卫星俯瞰是**运行时联网**取瓦片在浏览器拼合，不落地保存、不重新分发，仅在页面上标注来源。
2. **攻略帖**：不做爬虫、不转载正文，只做站外搜索跳转 + 关键词复制 + **原样 iframe 内嵌**（页面仍由平台提供，跨域读不到内容，也不开放顶层跳转权限）；用户行为完全发生在平台侧。
3. **底图与实时路况**：高德瓦片来自其公开瓦片服务（**非官方接口、无 Key、随时可能失效或限流**），只适合原型；境外底图用 OSM（**© OpenStreetMap 贡献者，ODbL**，保留署名）与 Esri World Imagery（**© Esri、Maxar、Earthstar Geographics**）。
4. **界线（重要）**：地球层的中国国界 / 岛屿来自 DataV.GeoAtlas，南海断续线用其 `100000_JD` 要素，**只是演示用的示意界线**，没有经过地图审核。正式上线**必须**替换为自然资源部「标准地图服务」审核过的界线数据（含台湾、南海诸岛、藏南、阿克赛钦等要素的完整表示），并按《公开地图内容表示规范》报审；地球层陆地轮廓来自 Natural Earth 1:110m（公有领域）。
5. **坐标与国界用语**：海外坐标是 WGS-84 近似值，与 OSM 一致，但都是演示精度；两岸 / 领土表述以正式发布时的审核稿为准。
6. **隐私**：图库 Key、我的照片、收藏、道路透明度、图源选择都**只存本机 `localStorage`**，页面没有服务端、不上传任何用户数据。

## 已知限制

- 数据是人工精选的示例集（v10 起中国每城 15 个景点、海外每城 5 个，热度值是示例排序），**不是实时热度 / 完整 POI 库**；开放时间、门票、预约要求请以官方渠道为准。v10 新增点位带**参考票价**（`免费` / `¥xx`），淡旺季、联票与预约政策都会变，**不是实时报价**。
- **Commons 这一路在当前网络下不可达**（实测 ECONNRESET / TIMEOUT，Wikimedia 系与部分境外站点在本地被拦），所以图集里 Commons 只会显示「不可达」；在能访问的网络里它会正常返回自由许可照片。
- **Pexels 官方 API 的跨域**：其图片 CDN 已实测 `ACAO:*`，但 API 响应未在错误态回 `ACAO`（需要自己的 Key 才能验证成功态），所以默认推荐路径是 **Unsplash（实测 `ACAO:*`）**，Pexels 作为并列选项；如果浏览器报 CORS，页面会把它如实写进图源状态里。
- 高德 / OSM / Esri 都是**公开瓦片或公共镜像**，**不保证可用性**；被限流时底图或卫星图会缺块（页面会显示「x/12 块瓦片」如实反映）。本机对 `tm.amap.com`（路况）与 `a.tile.openstreetmap.fr` 有 TLS 拦截（`ERR_CERT_VERIFIER_CHANGED`），属环境问题，页面会把路况标成不可用而不是假装有数据。
- 平台搜索 URL 结构可能调整；正式版建议由服务端下发链接模板（页面里已集中在 `POST_PLATFORMS` / `VIEW_PLATFORMS` 两个数组，改起来只改一处）。
- 没有账号体系、没有服务端，所以清单只能在单机单浏览器里同步。
- **行程助手默认仍是「规则生成」，不是 AI 生成**：预算 / 里程是演示级估算（按站内坐标与经验区间算），不反映实时票价与拥堵；具体餐厅、预约与闭馆提醒要自己再核对（或用页面上的「交给站外 AI 细化」口令去问）。**v7 的站内 AI 是可选通道**：你填自己的 Key（浏览器直连服务商、Key 只在本机）或点「启动本地模型」（v12.1 起为 WebLLM 0.2.86 + Qwen3.5）才联网；发给模型的只有你当前看到的行程与问题，本站不代理、不存对话，输出内容请自己复核。

## v8 ① 行程：同一个景点不再反复出现

问题长什么样：v7 的「天数一颗不少」是靠**轮转复用**实现的（点位排完就从头再来一遍，标个「二刷」）。截图里成都固定 7 天、南京 4 天时，同一个夜景点「夫子庙·秦淮河」连着四个晚上都在，白天点位也反复出现 —— 天数是对的，行程是假的。

现在的做法（都在 `plBuild()` 里，一眼能看出「取一个少一个」）：

- **白天点位一条队列**：`dayQ = walk.slice()`，每天 `splice(0, per)` 取走，取完就没了；一趟行程里同一景点最多出现一次。
- **夜景点单独一条队列**：`nightQ` 只装 `cat === 'night'` 的点位，一天最多一个；当天的夜景优先挑**离当天最后一个白天点位最近**的那个（少折返），整趟不重复；实在没有就留白，不会拿白天的点位顶夜景。
- **两餐也从榜单往下取**：`eatQ` 是这座城市榜单里的必吃清单，一天取 2 个，同一趟里不重复（取完就只写「按榜单自选」）。
- **点位排完的城市**：剩下的天数不硬凑，写成「放慢节奏 / 自由活动」，并在提示里说清「这座城的 N 个点位已经在前面 X 天排完，想更紧凑就把天数减到 X 天」。
- **换城那天加一行城际段**：`plLeg(前一城, 后一城)` → `plRailBetween()` 先找**同时经过两城的直达干线**（报「成都东 → 西安北 · 西成高铁」）；没有直达就找**一次换乘**（一条线停 A、另一条线停 B，两条线共用同一个城市站点，报「北京西 → 郑州东 · 京广高铁，在 郑州东 换乘 徐兰高铁 → 西安北」）；连换乘都没有才按直线距离给「高铁 / 飞机 / 长途车」的建议。这三种都写明「班次（与换乘站）以 12306 为准」。
- **自检字段**：`__CTA_PLAN_LAST` 多了 `uniq`（不同景点数）、`dups`（重复出现次数，必须为 0）、`free`（整天空白的天数）、`names`（逐日点位名）、`legs`（城际段），探针 `v8Dedupe` / `v8PlanLegs` 与 `verify-v8.mjs` 都拿它们断言。

取舍说明：v8 起**不再有「二刷」这个概念**（只在自由活动那天的建议文字里出现「想多看一次也可以自己去」这类说法）。天数仍然一颗不少 —— 少的是「重复」，不是「天数」。

### v8 ② 修复：高分屏下铁路线整片「飘到海里」

起因：`#net` 是 `<canvas>`，而 canvas 属于**替换元素** —— 只写 `position:absolute;inset:0` 时它的 `width` 仍是 `auto`，浏览器会拿**位图宽度当 CSS 宽度**。位图是 `vw × dpr` 开的，所以在 **devicePixelRatio > 1** 的机器上（Windows 150% / 200% 缩放、浏览器缩放到 110% 以上都算）画布的 CSS 盒会变成 `vw × dpr`，整张位图再被拉伸一次：**整层铁路以画布左上角为基准放大 2 倍**，西边看着还对，东边全飞到黄海 / 东海 / 日本海去了（用户实测截图就是这个样子）。headless 探针默认 `dpr = 1`，所以之前的自动化一直没抓到。

改了三处（都在 `index.html` 的 `Net` 模块 / `#net` 规则里）：

1. **`#net{position:absolute;inset:0;width:100%;height:100%}`** —— 宽高显式 100%，画布盒永远等于地图盒，位图再大也只是「更清晰」，不会被拉伸。`check.mjs [15]` 现在会拦「只写 inset:0」的回归。
2. **位图按画布自己的 CSS 盒开**（`fitCanvas()` 用 `cv.clientWidth / clientHeight`，不再用回调里的 `vw/vh`），并整块 `clearRect`；**几何一律取 `MapView.zoom / center` 的当前状态**，不用 `onDraw` 回调的快照 —— 开关图层 / 布局刚变的那一帧拿到旧快照，同样会画出一批错位的线。
3. **自愈**：画布盒和地图记的 `vw/vh` 差超过 1px（窗口或布局刚变、地图还没重新量）就跳过这一帧，并在下一帧 `MapView.resize()` 重新量一次再画 —— 宁可晚一帧，也不画一张错的。

回归怎么防：`v8NetMap` 场景改成**在 dpr=2 下跑**，`probe-dom.mjs` 多读三项 `align` 数据交给 `verify-v8.mjs` 断言 —— 位图必须正好等于 `CSS 盒 × dpr`（`stretch = 0`）、京沪高铁「南京南—上海虹桥」之间必须读到铁路像素、**台湾以东的公海必须一个像素都没有**。截图 `tools/_shots/v8_netmap.png` 也变成 2 倍分辨率，可以直接肉眼看线有没有贴在地图上。

## v7 ② 行程助手：天数一颗不少 + 按城市微调

## ① 内置图片扩容（只做中国）

先说结论：**这轮没能靠图库搜索页批量拿图**（被反爬），所以把「每个景点都有真实影像」做在了**卫星实景**这条路上 —— 它是真实影像、不需要图库许可、每个景点都拿得到。

实测台账（`node tools/probe-images.mjs` → `tools/_shots/_images.txt`，构建期检索日期 2026-10-16）：

| 图源 | 实测结果 | 能不能当内置图 |
| --- | --- | --- |
| Unsplash / Pexels / Pixabay **搜索页** | **401 / 403 / 403** | ❌ 拿不到「关键词 → 图」，没法按景点检索 |
| `images.pexels.com` / `images.unsplash.com` CDN | 200 + `ACAO:*` | ✅ 可直链，但只有逐张看过内容的那几张（`PHOTO_PICKS`） |
| `cdn.pixabay.com` | 403 | ❌ |
| `upload.wikimedia.org` / Commons / Openverse | 连接失败（本机被拦） | ❌ |
| 官方 API（Unsplash / Pexels / Pixabay） | 401 / 401 / 400（都需免费 Key） | ✅ 用户自配 Key 可用（v4 起已支持） |
| **高德卫星 z16 / z17、Esri 影像** | **200 + `ACAO:*`** | ✅ **内置真图主力**（能拼图、也能导出 PNG） |

于是内置图片这一轮做了四件事：

1. **实景三档**：`SAT_ZOOMS` = 街道级 z17（约 600m）/ 街区级 z16（约 1.2km，默认）/ 城区级 z14（约 5km），三档共用 `satPaint()` 拼 4×3 张瓦片，图集里点档位就重拼；
2. **同城实景图墙**：`drawCityWall()` 给该城每个景点各拼一张 z15 + 2×2 的小影像（最多 8 张），点一张直接切到那个景点 —— 相当于「每座城市至少 5–6 张真实影像」；
3. **存成本机 PNG**：瓦片用 `img.crossOrigin = 'anonymous'` 取（实测 ACAO 都在，画布不被污染，`toDataURL` 有效）；**万一张源没有 ACAO 会自动回退到普通模式并标记 `satState.tainted`**，界面如实说「请右键另存」，不假装导出成功；
4. **「我的照片」增强**：单条直链 / **多行批量** / **拖拽图片文件到图集区**三条入口，加上**导出 / 导入索引 JSON**（本机之间搬）与 **🩺 图片体检**（用 `new Image()` 真加载每条链接，报出哪些已失效或被防盗链）。

对应场景：`v6Sat`、`v6SatZoom`（切到 z14 会重拼）、`v6Chk`（点一次体检，报告里能看到「N / M 条可加载」）。截图：`tools/_shots/v6_sat.png` / `v6_satzoom.png` / `v6_chk.png`。

## ② 行程助手（只做中国）

**它是什么**：顶栏 `🤖 行程助手` 打开一整块面板 —— 选**目的地**（v7 起 95 座中国城市，按省份分组 + 可搜索，可多选，也可以「不指定」）→ 拖**天数**（v7 起 1–30）→ 选**节奏**（轻松 2 点 / 标准 3 点 / 紧凑 4 点）→ 勾**偏好**（人文 / 自然 / 美食 / 街巷 / 夜景，只影响排序）→ 生成**逐日行程**。

**每天给到什么**：

- **上午 / 下午 / 晚上**三段安排（夜景类景点自动排到晚上）；
- **点与点怎么走**：按站内经纬度算球面距离，< 1.2km 给「步行 / 骑行」、< 8km 给「地铁或公交」、再远给「打车 / 包车」，并附公里数；
- **今天吃什么**：从该城的必吃榜轮着来（v6 第③件事的数据）；
- **参考路线 + 预算区间**（元 / 人 / 天，标注「演示级估算」）；
- **路线地图**：`plDraw()` 用高德真实瓦片做底图（GCJ-02，显示前做 WGS-84 → GCJ-02 偏移），再叠城市大点（标 D 几）、当天小点（标顺序）、同城连线与比例尺；保留「🇨🇳 全国概览 / 🗺 路线范围」切换，瓦片被拦时仍显示路线；
- 一键 **复制行程文本** / **下载 `.txt`**，以及 **交给站外 AI 细化**（把「目的地 + 天数 + 节奏 + 偏好 + 已排地点」拼成口令，给 Bing / 百度 / 知乎 / 马蜂窝四个入口，**只跳转，不代问、不抓取**）。

**算法**（v6 版，写在 `index.html` 的注释里）：城市权重 = 热度 + 景点数 ×3 + 命中偏好数 ×6 → 分配天数（v6 时单城 1–3 天，余数补给天数最少的城市 —— **v7 已经把封顶撤掉，改成最大余数法 + 按城市微调，见上面「v7 ②」**）；城内先把偏好加权高的当起点，再**按距离做最近邻**串起来（少折返）；最后按节奏切时段、挂必吃与路线。

**为什么默认不用大模型**：行程的难点是取舍与顺序，本站有数据（159 城 / 1795 景点 + 100 城榜单），规则算得又快又稳，而且**不联网、不要 API Key、计划不出本机**。v7 把「用不用 AI」交给你自己决定：面板里填 Key 或启动本地模型才联网（见「v7 ③」），`check.mjs [14]` 会确认首屏没有任何外链脚本、Key 只落本机。想更细（具体餐厅、实时票价、天气）也可以继续走站外。条件记忆在本机 `cta.plan.v1`。

对应场景：`v6Plan`（北京 + 西安 4 天）、`v6PlanAuto`（不指定城市、6 天自动选城）、`v6PlanJump`（点行程里的地点 → 打开该景点抽屉并收起助手）。

4. **卫星俯瞰**（真实影像）；

取不到图时的空状态也换了：不再是一堵 7 张外链卡片，而是一段 **「这个地点还没有照片」+ 三条立刻能看到照片的路子**（配 Key / 加自己的照片 / 展开站外画廊）+ 一个「⬇ 去配 Key / 加我的照片」按钮，点完直接滚到图源设置。

**「同城精选」回退**：某个景点没有内置照片时，会自动退一层用**同城的**内置照片（`PHOTO_PICKS[city.id]`），并在状态行写明「该景点暂无专属照片：先看『北京』同城精选 N 张」——**只放确实拍的是这座城市的照片**，不会拿别的城市的图来充数。

**为什么内置照片没有做到「每个景点都有」**（如实说明，也是本项目一贯的底线）：

- 本机网络实测：`commons.wikimedia.org` / `api.wikimedia.org` / `upload.wikimedia.org` / `api.openverse.org` **全部超时或被重置**（Wikimedia 系整体不可达），所以「无需 Key 的 Commons 图源」在这台机器上取不到图；
- Pexels / Unsplash 的**官方 API 都要 Key**（页面已支持填你自己的免费 Key，只存本机）；它们的站点搜索页一边 **403**、一边 **Cloudflare 人机验证**，用真实浏览器（CDP + Edge）打开同样被验证页拦住，所以**没法在构建期批量抓一批可直链地址**；
- 可达的图片搜索（Bing）返回的是新浪 / 凤凰 / 699pic 这类**版权或商业图库**的图，**不能**拿来当「免费可直链」素材（底线：不转载、不使用来路不明的图、不用 AI 图凑数）。

所以 v5 的选择是：**把能拿到的图以照片的形式铺满图集 + 把「拿图的三条路」做到一步之遥**，而不是用一堆外链假装有图。填一个免费 Key（Unsplash / Pexels 各 30 秒申请）后，`loadPhotos()` 会走官方 API 把照片直接贴进同一个照片墙，署名与许可逐张照写。

## ③ 城市层不再漏城市名

`placeMarkers()` 原来是「热度高的先放，撞上就只留光点」，国家层城市一密（长三角、珠三角）就会看到「有光点、没名字」。v5 改成：

- **13 方位候选**：每个标签依次尝试 右 / 左 / 右上 / 右下 / 左上 / 左下 / 正上 / 正下，都不行就再往外挪一格（更远右上 / 更远右下 / 更远右 / 更远左），**最后才把名字居中压在光点上** —— 宁可名字压住一个光点，也不要缺名字（用户的原话）；
- **实测尺寸**：标签宽高与相对光点的偏移用 `offsetWidth / offsetHeight / offsetLeft` **量一次缓存**（原来用 `name.length * 13` 估算，中文 + 热度胶囊误差很大）；地图还藏着（`offsetWidth = 0`）时不缓存，等可见了再量；
- **摆标签不动光点**：只给标签本身加 `translate(dx, dy)`，光点始终钉在坐标上；
- **一键全显**：顶栏新增 **「🏷 标签：自动 / 全部」**（`#btnLbl`）：「全部」模式下连被判定为重叠的名字也照显（可能叠一点，但**不缺名字**），选择记在本机 `localStorage`；
- 城市标签优先于景点标签（按 `heat` 排序占位），所以国家层优先保证**城市名**齐全；低缩放（`zoom < 9.8`）时仍按原设计只显示城市名，避免景点名在省域尺度互相压住。
- **国家层镜头按城市包围盒自适配**（`countryFocus` + `MERC_Y`，v5 收尾补的）：老写法按「城市离质心多远」查表给缩放，对「两座城市离得远、质心落在中间」的国家会明显给大了 —— 希腊（雅典 ↔ 圣托里尼）与葡萄牙（里斯本 ↔ 波尔图）都被给到 z10.2，**两座城市的光点双双落在画面外**（实测 `markersShown = 0`）：国家层只剩一片空海，城市名一个也看不见（用户报的「漏城市名」里最严重的一种）。现在用 Web Mercator 量出城市包围盒，再按视口尺寸反推缩放（四周留 12% 给标签，上限 z15），希腊 **z8.4**、葡萄牙 **z7.7**、开局 **2/2 城市名都在**；中国层因为镜头更贴包围盒，名字齐全度也从 20/21 变成 **21/21**。量不到视口（首屏还没布局）或只有一座城市时，才退回老的那张表。

## ① 选中地图文字后地图拖不动 → 已修

**根因有两半**，都在 `index.html` 的 MapView 里：

1. `pointerdown` 里写着 `if (e.target.closest && e.target.closest('.mk')) return;` —— 光标只要落在**景点 / 城市的标签文字**上，这次按下就被整段丢掉：既不起拖拽也不接管指针，地图一动不动，感觉像「卡住了」；
2. 标记文字当时**可以被框选**（`.mk-lb` 没设 `user-select:none`），一旦选中，从文字上拖拽只会拉出一片蓝色选区。

**修法**：

- CSS：`#mapview,#mapview .mk,#mapview .mk *{user-select:none}`（署名 `#mapAttr` 例外，它要能复制）；
- 交互改成**先记起点、位移超过阈值才算拖拽**（`const DRAG_SLOP = 4`）：没超 4px → 什么都不做，交给标签自己的 `click`；超了 → 这时才 `setPointerCapture` + 加 `.dragging`，并顺手 `getSelection().removeAllRanges()` 清掉页面上已有的选区；
- 再加一道「拖完 200ms 内忽略标签 click」（`draggedRecently()`），避免「拖完地图顺手把景点打开了」；
- 顺带把 `.mk` 光标改成 `pointer`，拖拽时回到 `grabbing`。

> **v6 复盘又补了一刀：问题的另一半不在标签上，而在「提示条吃了指针」。** 用 CDP 真鼠标事件**逐事件记目标元素**才看出来：`pointerdown` 正常落在 `SPAN.mk-lb` 上，可 `pointermove` 落在了 **`DIV#hud`** —— 左下角那块提示条。`#hud`（以及 `#globeTip` / `#toast`）是 `#mapview` 的**兄弟节点**，提示文字长、会自动换行，于是它在左下角占了一大块；没设 `pointer-events:none` 时，指针一移进去，`pointermove` / `pointerup` 就派发给它、**不再冒泡到 `#mapview`**，MapView 永远收不到那次「超过 4px 阈值」的移动，抬指时 `endDrag` 走 `if (!moved) return;` → **地图不平移、`dragCount` 也不加**。症状很有迷惑性：按下能按住（`pointerdown` 是好的），光标一划进提示条就断，只要拖拽路线不经过它又一切正常。修法：`#hud,#globeTip,#toast{pointer-events:none}`（三块都只有文字，没有按钮 / 链接，不吃指针不损失交互），`check.mjs` 第 11 组加了对应断言防回归。复现 / 对照脚本留在 `tools/_shots/_dragdiag.mjs`（`label` 从标签上拖 / `map` 从地图空白处拖 / `label2` 逐事件记目标 —— 前者挂、中者正常，就是这个坑的指纹）。

**怎么验证**：`probe-dom.mjs` 支持用 CDP 派发**真实鼠标事件**（`down` / `move` / `up`，`pt:` 取标签中心），场景 `dragLabel`（从标签文字上拖 100px）、`dragLabelSel`（先在别处造 30 字选区再拖）、`clickLabel`（同一点只按不拖）；`verify-v4.mjs` 断言：地图平移次数 0→1、中心经纬度真的变了、hash 没被误改、选区被清空、标签 `user-select` 为 `none`，同时「点标签仍能打开景点」。

## ② 站内查看攻略帖（iframe），可嵌入性逐平台实测

抽屉「攻略帖」页签顶部新增 **「▷ 站内查看」**：平台 chips → iframe 内嵌平台页面，工具条给「↗ 新标签打开 / ⧉ 复制直链 / ⟳ 刷新 / ⤢ 放大 / 收起」。

| 平台 | 实测结果（本机 HTTP 头探测） | 站内查看 |
| --- | --- | --- |
| **B站** `search.bilibili.com/all?keyword=` | 200，**无 `X-Frame-Options`、无 `frame-ancestors`** | ✅ 站内直接看（`player.bilibili.com` 同样可嵌） |
| 小红书 `search_result` | 200、未声明禁嵌，但**通常弹登录墙** | ⚠️ 试一试 |
| 抖音 `/search/` | 200、未声明禁嵌，可能过人机验证 | ⚠️ 试一试 |
| 马蜂窝 / 知乎 / 百度 | 202 / 403 / 302（人机校验、风控） | ⚠️ 试一试 |
| Pexels 搜索页 / 图虫 / 索尼世界摄影奖官网 | `X-Frame-Options: SAMEORIGIN` | ❌ 只能外链 |
| 大众点评 / 去哪儿 | 本机 TLS 被拦截 / 只剩 JS 空壳 | ❌ 只保留站外跳转 |

- **判定方式**：跨域读不到子页面内容，所以只用 `load` 事件 + **10 秒超时**；超时就把遮罩文案改成「没能加载出来 —— 平台可能拒绝被嵌入，用下面的『新标签打开』照样能看」，绝不假装成功。
- **安全**：iframe 的 `sandbox` 给了 `allow-scripts allow-same-origin allow-forms allow-popups allow-popups-to-escape-sandbox`，**故意不给 `allow-top-navigation`** —— 平台用 frame-busting 脚本也顶不掉整页。
- **默认不预加载**：查看器收起时 iframe 没有 `src`，只有点了平台 chip 才会联网请求第三方页面。
- **合规**：内嵌页面仍由平台提供，本站不抓取、不转存其中正文与图片；`check.mjs` 会检查代码里**没有任何指向平台站点的 `fetch`**。
